MASTER PROMPT — AHC 2027 WEBSITE
Build a modern, responsive web platform for AHC 2027, organized by FRACO.

The website should not feel like a simple event landing page. It should function as a complete event and community platform with:

1. Public-facing website
2. Merchandise e-commerce
3. Event and program information
4. Sponsorship and partnership applications
5. Vendor registration
6. University Fair registration
7. Participant registration
8. Participant dashboard
9. Admin dashboard / CMS

The website must be modern, clean, professional, youthful, and community-oriented.

The visual identity should feel premium but friendly, with strong typography, generous spacing, rounded cards/buttons, subtle animations, and a consistent visual system.

The primary website navigation should be:

HOME
ABOUT
